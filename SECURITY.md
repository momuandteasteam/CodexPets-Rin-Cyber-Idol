# Security Policy

## Supported version

最新版の`main`ブランチのみを対象とします。

## Reporting

このリポジトリは画像、JSONマニフェスト、ローカルインストールスクリプトを配布しています。配布ファイルの改ざん、悪意のある導入手順、スクリプトの脆弱性、機密情報の混入などを見つけた場合は、公開Issueに詳細を書かず、GitHubの非公開脆弱性報告が利用できる場合はリポジトリのSecurityタブから報告してください。

This repository distributes artwork, a JSON manifest, and local installer scripts. If you discover tampered release files, malicious installation guidance, a script vulnerability, or exposed secrets, do not disclose details in a public issue. Use GitHub private vulnerability reporting from the repository's Security tab when available.

通常の表示不具合やアニメーションの問題は、公開Issueで報告できます。
