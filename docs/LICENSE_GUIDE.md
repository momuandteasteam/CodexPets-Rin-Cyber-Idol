# ライセンス利用ガイド / License Usage Guide

この文書は[氷色りん個人利用ライセンス](../LICENSE.md)の理解を助けるための要約です。正式な条件は`LICENSE.md`が優先します。

## 許可される例 / Allowed examples

- 正規のGitHubリポジトリから自身の端末へcloneまたはダウンロードする
- 自身が管理する端末のCodex Desktopへ氷色りんをインストールする
- 個人・非商用で氷色りんをローカル利用する
- 自分だけが利用できる私的バックアップを作る
- 正規リポジトリのURLを友人やSNSで紹介する
- GitHubの標準機能でforkを作る
- 文書、導入スクリプト、設定、QAメタデータの改善をPull Requestで提案する

## 許可されない例 / Prohibited examples

- スプライトやリポジトリのZIPを第三者へ送る、別サイトへ再アップロードする、またはミラーする
- 別のPetパック、アプリ、ゲーム、素材集、リポジトリへ同梱する
- 販売、広告、収益化、業務利用、商品化に使う
- フレームや画像を抜き出してアイコン、スタンプ、動画素材などへ転用する
- 色替え、衣装替え、変形、変換、派生キャラクター等を作成・公開・配布する
- AIモデルの学習、微調整、評価、特徴抽出、データセット作成に使う
- GitHubのforkを、GitHub外での再配布や別用途利用の根拠として扱う

## 再配布とリンクの違い / Redistribution vs. linking

正規リポジトリのURLを共有することは再配布ではなく、許可されています。ファイル本体、ZIP、抽出画像、コピーしたパッケージを第三者へ渡す行為は再配布であり、許可されません。

Sharing the URL of the official repository is permitted and is not redistribution. Giving another person the files, a ZIP, extracted images, or a copied package is redistribution and is not permitted.

Rights granted directly to users, GitHub, and its affiliates by the GitHub Terms of Service remain governed by those terms. A fork does not authorize off-platform redistribution, commercial use, asset extraction, visual derivative uses, or sublicensing.
