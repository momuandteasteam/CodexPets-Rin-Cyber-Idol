## レビュー済みの注意点

- `067.5°`、`112.5°`、`292.5°`は上下方向の動きが控えめです。通常サイズのラベル付き確認で、期待する象限と順序を確認しています（13 pass / 3 warning / 0 fail）。
- 下腿とコート裾の間の意図的な隙間が、透明領域の警告として検出されています。胴体や顔の欠損ではありません。
- `157.5° → 180°`に差分量の統計的警告があります。足元・サイズを維持し、下向きへの移行を確認しています。
- 視線2行は全16ポーズ共通のスケールで配置し、お団子ヘアの上端が切れない余白を確保しています。
- このPetでは独立したブラインド軸判定は実施していません。

## インストーラー

- macOSでPOSIXシェルの構文検査と、空白を含む任意パスへのインストール・再インストールを確認しています。
